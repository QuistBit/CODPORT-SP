# OPT R50B — narrow callback-free Session view for item admission

Base R50A eddb596379db41403a08f5315c978ec718f6bdc3, gameplay control R47L. R50A was already present at branch head when this pass started. Do not duplicate its native model-prefix query. R47L pickup measurements were 121/74/40/39/50 ms, not a direct measurement of the following optimization.

Audit: gsc_session_snapshot copies the public view and collects active thread counts (gsc_active_threads walks each task directory) plus native and fog diagnostics. Item CurrentChecked, item Time, WeaponRegistrationScope and Begin consume only session identity, error presence, state and logical clock. The previous successful Scope invokes two full snapshots; Begin invokes four including its final Scope. The Session snapshot's stats and task-count providers are pure reads. No callback or write intervenes between the two clock reads in Scope/Time/Begin; GscTestItemIdentityChecked proves the same Session owner and the intervening registry revision and byte comparisons are synchronous. Introduce a three-field by-value internal query valid/state/logical_ms that checks exact session_id and error[0]. A single query suffices per CurrentClockChecked call. Preserve all original owner, mode, map, registry, marker, server time, cancellation and before/after callback checks. Full snapshot API unchanged for other callers. No persistent clock cache, no public syscall or execution admission changes. Separate current header avoids the historical 609A header overlay. As R50A adds a paired native syscall, the final integrated build must rebuild EXE and GAME together.

Verification actually performed locally: reconstructed exact old/new item, scope, begin, snapshot and clock fragments matched connector lengths and FNV-1a, including item 1435/1551 (50087af1/6e83d80c), scope 1510/1393 (b9fbd7a5/cba2c330), begin 817/765 (2c49bd7f/8014b07e), snapshot 522 (784ffa37), clock 517 (50d8de17) and header 411 (877cb641). Full source replacements were reversed to reproduce the pinned originals. Exact test fragment hashes are checked by the reproduction driver. Fixture Git blob 667b5af37c410f21ef738ca5076783b03b1def06. GCC and Clang C11 O2 -Wall -Wextra -Werror plus Clang O1 ASan/UBSan each passed 28691 scenario comparisons (16 successful Begin). Tests compare admission outcomes, captured time, returned lease bytes and guard/serial state, including stale session, invalid clock/error, wrong registry, operation or marker, cancellation, reentry and mismatched server time. Runtime/registry and identity providers use controlled stubs; the actual extracted snapshot and new clock plus changed admission functions are compiled, not the full Session/GAME. For a simulated 64+16 task directory successful Scope no longer requests either full thread census (160 modeled task inspections to 0) or native/fog stats (4 to 0). This is a work count, not measured speedup. Local runs used reconstructed fragments and fixture, not the complete checkout driver. No MSVC build, native VM or game acceptance.
