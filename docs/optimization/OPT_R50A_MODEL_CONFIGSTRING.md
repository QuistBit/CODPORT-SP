# OPT R50A — one callback-free server model-prefix query per lookup

Base R49C b7e3dcd96fc0c7c56b2c7b4bc67624e316fd55a1; gameplay control R47L. R47L pickup diagnostic times were 121, 74, 40, 39 and 50 ms; the user reported no visible delays. Source audit: WeaponRegistrationModel searches the occupied model-configstring prefix, with full WeaponRegistrationScope (including exact CAR registry comparison) before and after each individual read. The actual SV_GetConfigstring provider only copies from the server-owned string or returns empty; it has no callbacks on valid arguments. A single native-only read-only syscall now finds the first case-sensitive match, stopping at the first null or empty slot, never reading reserved slot 0. No caching, writes, precache, callbacks or resource pointers returned. Valid model names have at most 63 bytes (MAX_QPATH=64), so legacy truncation at 1023 bytes cannot create an extra match. The GAME retains both full outer scope fences, the resource QUERY/VALIDATE sequence, and the final separate configstring read. If the paired provider reports -1 (not native/current VM), the old lookup loop is retained. Inventory and pickup transactions are untouched.

Paired native ABI extension G_COD1_FIND_MODEL_CONFIGSTRING_R50=1050, in a separate current header because g_syscalls.c uses the 609A historical g_public.h overlay. EXE and GAME must be rebuilt together: older EXE does not recognize this new trap and would error, not return -1. No QVM support is added. No claim of ABI compatibility with old executables. No change to existing trap numbers. The complete native compile/link and actual VM dispatch have not been tested.

Actual local verification: exact new helper header 507139aa1c0b92c3ce4a8ecf6c7586fa8e7011dd, ABI header 302e7a3f469911b7aefc504ff7bd9fa86dccb6d2 and lookup fragment 2208f03811fa12e9522d98b078eeef12d5e520ca. Fixture blob 23d59c7e6d46f34889e0597517775797ff0fa26d. GCC and Clang C11 O2 -Wall -Wextra -Werror, plus Clang O1 ASan/UBSan: 10007 differential cases each PASS, including absent, duplicate, reserved slot, gaps, full prefix, long stored string; extra invalid name, retirement and invalid returned index checks. Actual test uses new helper and lookup fragment, with controlled scope/provider stubs and reference copy/truncation semantics; it does not execute SV_GameSystemCalls or the real GAME. For a synthetic hit at slot255, old lookup 255 reads and 510 scope calls, new lookup one server scan and two scope calls. Both still examine the model prefix in server memory. This count excludes subsequent model-resource validation and does not measure FPS or pickup duration.
