## Source audit
On a successful non-paused phase session_r237_phase53 checks Session identity and private output storage, frame identity, resources before VM, resources after VM, then session_after_vm checks animation resources again and captures stats and active-thread state. Animation resource validation calls start-origin, namespace, turret and developer certificates as selected; actor bootstrap may call a separate map certificate. These callbacks can reject or change state, so no result is cached across callbacks. Runtime overlap checks also guard allocation and private output ranges. r237_dispatch_task53 refreshes state/wait ownership and validates TimeRoot before source execution. These are candidates, not proven causes of R52 stalls.

Emit corresponding raw tick fields and task_guard_calls in existing OPT_VM53 line. Keep cvar, slow-phase threshold and sampling unchanged. No native callback, resource check, scheduler order, task budget or pause behavior intentionally removed or changed. No added allocation. Profiling incurs clock-call overhead; use off/on runs for comparison. Individual native methods are still included in source, not separately timed. Session profile output storage check outside admission remains in total only. For failed phases, timing can include failure cleanup; do not sum nested timings.
