# OPT R54D2 — scoped dirty journal inside the reference scheduler

Base 57cdc3f1e01bfdfdaad5b25113c27dded31a9586. Reference drain integration f9febc8386f2d545824718660e44cef926d1c160; GAME logging e1f74c5bf884990fa2840bc78bbe142bbb50f908.

## Behavior
Windows x86 WIP: +set g_cod1VmProfile 1 +set g_cod1QueueDirty 1 enables independent diagnostic mode; g_cod1QueueShadow is optional and can remain 0. Default off. One local scratch journal per uninterrupted drain, with 1024 physical slots. Runtime pointer is cleared after the drain returns, including pause and failure; explicit destruction guard while scratch is attached. New allocations/reuse, validated queue offers (including idempotent offer), dispatch dequeue, endon cancellation, stale wait owner and identified entity/animation certificate retirements mark affected slots. Synchronous immediate tasks are covered in part by acquisition marks; this is not an exhaustive proof of all status writes. The mark helper currently searches physical directory by pointer and is linear; optimize this before authority. No journal allocation, new gameplay scheduling choice or changes to original callback order intended. Existing full scan and its errors remain authoritative. After each successful reference selection, reconcile changed slots and audit all physical rows, including non-head entries, then compare head or next deadline. Skip/invalid/mismatch never changes dispatch; invalidate and reseed at next boundary. Overcapacity is a diagnostic skip. Original rejected scans do not reach audit. Scope deliberately does not span phase returns, exclusive deadline advances or GAME calls between drains. Nested calls are not a supported new VM capability.
OPT_DIRTY54 scope=epoch reports cumulative per-lane counts/ticks for valid timed host samples, reset on map epoch; sampled log has possible unsampled tail and excludes invalid clock/epoch/time returns. checks=matches+mismatches+skipped; a skip is not a match. Mismatches force a log record, other lines follow slow/periodic policy. feeds counts candidate row updates including reseed; audit_rows counts independent full membership comparisons up to first mismatch. ticks excludes mark cost (mark is within dispatch or other callers). Both shadow modes enabled together increase stack usage; use dirty alone for mutation coverage. Do not benchmark FPS with diagnostics enabled.
