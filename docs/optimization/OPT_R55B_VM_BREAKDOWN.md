Base R55A ffc2a2d2b91d1539745ce324a2c047e24f1a77f9; production integration 7631a50b8cba55046cb472bf83563bf4085eb801.

## Changes
Opt-in +set g_cod1VmProfile 1 +set g_cod1VmBreakdown 1 (also enables R55A source attribution). Default off. On existing Windows x86 WIP profile path, attach a continuation-scoped observer to Results VM. Measure inclusive outermost duration per category, with nested calls of the same category counted but not timed again. Other categories can overlap, so do not sum them or subtract all from source. 72 call sites in gsc_vm_results.inc: 5 guard, 9 eval, 27 selected native-expression adapters, 31 selected native-statement adapters. Exact original source recovered by stripping just the 72 wrapper expressions. The wrapper evaluates the original int-returning expression once; original short-circuit conditions and return paths remain. No gameplay decisions depend on timing. No new allocations. Scope cleared after source returns; inherited scope remains intact. Legacy interpreter not instrumented. Runtime overlap and free guards include observer scope.

OPT_BREAK55 records raw QPC ticks, total and outermost invocation counts per category, sources, legacy sources and failed timings per published phase. Existing OPT_VM53 sampling policy still applies. These are inclusive selected adapter boundaries, not complete GAME callback instrumentation: guard can include host validation, eval includes nested guards and native calls, native categories can include nested scripts and local VM work. Not an opcode profile or exclusive attribution. Instrumentation calls the timer frequently when enabled; do not compare FPS with this diagnostic enabled.
