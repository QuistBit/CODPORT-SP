# OPT R54D3A — scoped address-to-slot index and native validation gate

Base R54D2 a563d2a8adf750b7f5e6d7e822a0bcff0f19be32. No changes to master. R237 remains authoritative in every mode.

## Implemented
Replace linear pointer-to-slot lookup during mutation marking with a bounded open-addressed index (2048 uint16 slots, 1024 physical Task slots). The map stores slot+1, not Task pointers, and verifies membership via task_at before marking. No foreign Task dereference. The index is built lazily inside each uninterrupted drain and extended only for newly allocated slots. Duplicate pointer, unknown address, shrink or overcapacity invalidates the journal; original selector continues. Existing assumptions about stable physical directory addresses and single owner thread remain. No allocation; scratch is scoped, pointer and extent cleared on return; runtime_private_overlap now includes complete scratch storage. Diagnostic storage only; no indexed dispatch yet. Retained full independent audit and original fallback/error behavior. Hash lookup is expected O(1), worst-case bounded linear probes, plus map construction. The R54D2 runner now pins the older scope/audit/drain includes to preserve historical regression compatibility.

OPT_DIRTY54 adds cumulative mark_lookups, mark_probes, map_rows and mark_misses. A mark miss triggers a log record. Existing counter scope and unsampled-tail limitations remain. mark_probes measures lookup probes only; map_rows measures entries inserted, not construction probes. Extra diagnostic overhead is not a game performance measure.
