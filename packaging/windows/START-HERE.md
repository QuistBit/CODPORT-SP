# CODPORT-SP 724A для Windows

1. Установите оригинальную **Call of Duty (2003)** для Windows. Понадобится папка с `CoDSP.exe` и каталогом `main` с оригинальными архивами игры.
2. Полностью распакуйте этот ZIP в отдельную папку, доступную для записи. Для перехода с предыдущей версии используйте новую папку.
3. Дважды щёлкните **Play-Training.cmd** и выберите `CoDSP.exe` в установленной оригинальной игре.
4. В главном меню выберите **Новую игру**, затем уровень сложности. После загрузки откроется дневник. Щёлкните по нему, чтобы начать миссию.

Для запуска из командной строки передайте путь к папке игры, например `Play-Training.cmd "C:\Games\Call of Duty"`. Настройки и журнал `profile\main\rtcwconsole.log` сохраняются в распакованной папке. Порт запускается в окне 800×600. Во время подготовки Training загрузка может занять больше минуты.

# CODPORT-SP 724A for Windows

1. Install the original **Call of Duty (2003)** for Windows. You need the folder containing `CoDSP.exe` and the original game archives under `main`.
2. Extract the entire ZIP into a separate writable folder. Use a new folder when upgrading from an earlier release.
3. Double-click **Play-Training.cmd** and select `CoDSP.exe` from your original installation.
4. Choose **New Game** in the main menu, then select a difficulty. When the diary appears, click it to start the mission.

To launch from a command prompt, pass the game folder, for example `Play-Training.cmd "C:\Games\Call of Duty"`. Your settings and `profile\main\rtcwconsole.log` are saved in the extracted folder. The port starts in an 800×600 window. The first Training load can take over a minute.
